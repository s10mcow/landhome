# Draft permit packets at new-property intake

Use this with the preliminary site-plan workflow when adding or onboarding a land-home property, or when asked to prepare a permit packet. Run permit discovery and the draft layout in parallel. Keep one intake and one parcel ID across both.

## Resolve the permit route

- Confirm the exact parcel, city limits, governing building department, road authority and applicable water/wastewater permitting offices. Resolve new installation versus replacement, new versus used home, and private versus public utilities. A mailing city is an address attribute and does not identify the permitting authority.
- Use the current official checklist and forms for the actual contractor/installer route. Record agency, permit type, portal or submission route, checklist/form URL, version or retrieval date, and stage due. A connected tracker catalog can seed discovery. Reconcile it against the agency's current requirements. Keep applicability unknown when the route or a requirement cannot be verified.
- For unincorporated Flagler County, start with [Central Permitting](https://www.flaglercounty.gov/Growth-Building/Central-Permitting), select its Mobile Home Contractor Packet, and check the linked manufactured-home application, driveway/right-of-way, drainage, tree protection, used-home and commencement forms for applicability and timing. Check the [Flagler water well program](https://flagler.floridahealth.gov/programs-and-services/environmental-public-health/water-well-construction/) for the applicable well route. For septic, use the applicable current [Florida DEP onsite sewage forms](https://floridadep.gov/water/onsite-sewage/content/onsite-sewage-forms-and-publications) and confirm the accepting office. Carry supporting well/septic permits or utility proof into the building packet where the checklist requires them.
- For Clay County, start with the [mobile-home permit guide](https://www.claycountygov.com/government/building-division/permit-applications-how-to-guides). For parcels confirmed inside Keystone Heights city limits, include the [city review](https://www.keystoneheights.us/building-department) before Clay County submission. Resolve other jurisdictions against their own primary sources. Keep collecting verified intake facts if a form or current checklist is unavailable.

## Build a shared intake

Use the parcel record and available project documents before requesting missing information. Store each permit field's value, source, date, and evidence status. Keep record owner, intended buyer, and authorized applicant separate, especially before closing. An appraiser record can confirm parcel identity but cannot establish authorization to file for someone else.

- **Parcel and scope** — site address, APN/parcel ID, verified legal description where requested, governing jurisdiction, documented installation or replacement scope, and verified applicable utility choices.
- **Parties** — owner and applicant, contact and mailing details, contractor/installer and trade contractors, credentials and role only when verified and applicable. Leave unknown party and credential fields blank.
- **Home and site** — documented manufacturer, model, year, serial/section numbers, footprint, bedroom count, area and floor plan. Keep layout assumptions in the preliminary plan. Leave technical, design, and attestation fields for the qualified party when required. Use exact field meanings, for example the area defined by the septic form.
- **Approvals and evidence** — distinguish permit application, accepted filing, issued permit, and final clearance. Use an issued permit number only from the actual matching approval. A draft or application receipt is separate evidence.

## Produce drafts and the upload checklist

1. Use current official blank forms. Prefill applicable, ordinary text and choice fields only from verified intake. For a fillable PDF, enumerate the actual fields and choices and map them to the verified data. Write a new unsigned draft copy, reopen it, and verify values and visual placement on every changed page. Keep signatures, initials, attestations, dates of execution, notarizations and seals for the authorized parties. Preserve originals and any existing signed or sealed evidence unchanged as separate attachments.
2. If a form is portal-only, unavailable, locked, or cannot be populated reliably, generate a copy/paste worksheet using verified field labels. If the current labels cannot be checked, provide a clearly labeled intake worksheet and list the form as needing verification. Distinguish generated PDFs from worksheets in the packet index. Use a clear draft filename or cover/index that identifies the draft.
3. Build an attachment index grouped by building/install, septic, well, driveway/ROW, and other applicable routes. Record the authority/portal, current form/source, status, source file or revision, missing item, owner, next step, and when it is needed. Use statuses such as draft filled, needs field data, needs signature, needs supporting document, needs agency approval, ready for PM review, and not applicable with a reason. List existing attachments such as ownership proof, current survey or signed/sealed plan where required, floor plan, manufacturer installation booklet, installer diagram, utility proof, and any issued permits. Record missing attachments instead of generating substitutes.
4. Keep the preliminary plan PDF/SVG separate from the official attachment list's approved or professionally prepared site plan. Carry its revision into the packet for traceability. For septic, prefill the applicant portion of the current application from verified facts and track the site plan and evaluator's site evaluation/design separately. On current DEP 4015, Applicant means the property owner and Agent means the owner's legally authorized representative. Use the form's habitable-area and bedroom definitions, and use the permitted road/locality option for an unassigned address only when verified. Flag permit materials affected by a later layout revision for recheck.
5. Return the preliminary plan, unsigned PDFs that were actually filled, portal field worksheet if needed, and an upload checklist grouped by authority. Summarize missing items that block filing. Mark the packet ready for filing only after applicable approvals, signatures, required attachments, and applicant authority have been verified against the current checklist. Save generated property files privately and keep them out of the shared skill repository.

Preparation is reversible. Signing, certifying, filing, paying, sending outreach, or changing a live portal record require separate authorization and the applicable responsible party.
